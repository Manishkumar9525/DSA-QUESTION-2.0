## ▶️ How to Run a Solution

Each problem is stored as a separate C++ source file. Compile and run the file you want to practice:

```bash
g++ Arrays/01_FindLarge_Element.cpp -o solution
./solution
```

On Windows, run the generated executable with:

```powershell
g++ Arrays/01_FindLarge_Element.cpp -o solution.exe
.\solution.exe
```

## 🧩 Problem-Solving Approach

For each problem, the focus is on understanding:

1. **Problem Statement**
2. **Input & Output**
3. **Example**
4. **Approach**
5. **Algorithm**
6. **C++ Implementation**
7. **Time Complexity**
8. **Space Complexity**

The aim is not just to write code, but to understand **why the solution works**.
